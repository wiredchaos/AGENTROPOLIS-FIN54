# Hermes Chief of Staff Operating Model

Status: architecture note
Scope: AGENTROPOLIS FIN54

## Core lock

FIN54 should use Hermes as a coordination and review layer, not as an autonomous financial actor.

Hermes can organize research, drafts, docs, tasks, and reports.

Human review remains required for high impact actions.

## FIN54 role

Hermes may help with:

- documentation
- task routing
- report drafts
- pricing notes
- operating checklists
- research summaries
- GitHub issue notes
- approval queues

## Operating doctrine

1. Draft first.
2. Explain assumptions.
3. Cite source docs when available.
4. Route work through GitHub.
5. Keep public and high impact actions review gated.
6. Save stable decisions into docs.

## Workstream loop

1. Brief
2. Context check
3. Draft
4. Review
5. Final output
6. Decision log

## Anti drift note

Hermes coordinates.

FIN54 stays review first.

GitHub records work.

NEURO remains the final approval layer.
